# Расписание Полины Молотковой

Отдельное Android-приложение только для преподавателя. Режима студента, выбора роли, сетевого парсера и лишних вкладок нет.

## Что уже сделано

- Расписание перенесено из `source/Расписание_Молоткова.xlsx`.
- Зелёные занятия из Excel считаются **нечётными**.
- Жёлтые занятия из Excel считаются **чётными**.
- ИДО и субботние занятия, которые в Excel заданы конкретными датами, показываются только в эти даты.
- Первая учебная неделя: **31.08.2026–06.09.2026**, нечётная.
- Есть переход по неделям, выбор дня и кнопка «Сегодня».
- Если занятие идёт прямо сейчас, карточка помечается автоматически.
- Интернет приложению не нужен: расписание встроено в приложение.
- Видимое название приложения: **«Расписание Полины Молотковой»**. Слово «бета» в названии не показывается.

## Как получить APK через GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки (важно: содержимое, а не саму внешнюю папку).
3. Откройте вкладку **Actions**.
4. Выберите **Build Android APK** и нажмите **Run workflow** — либо просто сделайте push в ветку `main`.
5. После успешной сборки откройте завершившийся запуск и скачайте artifact **MolotkovaSchedule-debug-apk**.
6. Внутри будет `app-debug.apk`, который можно установить на Android.

## Версия

`0.1.0-beta` — версия указана только внутри приложения/сборки и не добавляется к названию на экране телефона.

## Важное про чётность

Логика приложения основана на учебных неделях, а не на ISO-номере недели года: неделя с 31 августа 2026 года считается №1 (нечётной). Это соответствует цветовой логике исходного Excel.
